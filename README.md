# Roll to Efir

Roll to Efir — настольная утилита для подготовки эфирного MXF из сырого видеоролика произвольного формата. Пользователь выбирает исходное видео, пресет Adobe Media Encoder в формате `.epr` и путь для результата, а приложение собирает и запускает команду `ffmpeg`.

## Возможности

- дружелюбный GUI на стандартном `tkinter` без обязательных runtime-зависимостей;
- чтение распространенных параметров из `.epr`: разрешение, FPS, видео-/аудиокодеки, битрейты, частота аудио, каналы, тип развертки;
- генерация MXF через `ffmpeg` с отображением команды и лога выполнения;
- модульная структура для дальнейшей доработки: парсер пресетов, сборка команды и интерфейс разделены.

## Требования

- Python 3.10 или новее;
- установленный `ffmpeg`, доступный в `PATH`;
- для запуска тестов: `pytest`.

## Запуск

```bash
python -m roll_to_efir.gui
```

Или после установки пакета в editable-режиме:

```bash
python -m pip install -e .
roll-to-efir
```

## Как пользоваться

1. Нажмите **«Выбрать…»** рядом с полем «Исходное видео» и укажите сырой ролик.
2. Выберите `.epr` пресет Adobe Media Encoder.
3. Проверьте распознанные параметры в блоке «Параметры из .epr».
4. При необходимости поменяйте путь «Итоговый MXF».
5. Нажмите **«Создать MXF»** и дождитесь завершения `ffmpeg`.

## Ограничения текущей версии

Формат `.epr` не является стабильным публичным API Adobe, поэтому парсер извлекает наиболее распространенные поля по именам тегов, атрибутов и свойств. Если конкретный пресет содержит нестандартные ключи, приложение сохранит MXF с безопасными значениями по умолчанию и покажет нераспознанные параметры как «не задано». Архитектура позволяет расширить `roll_to_efir/preset.py` под конкретные EPR-файлы вещателя.

## Разработка

```bash
python -m pytest
```

Ключевые модули:

- `roll_to_efir/preset.py` — нормализация `.epr` в объект `EprPreset`;
- `roll_to_efir/transcoder.py` — сборка и запуск команды `ffmpeg`;
- `roll_to_efir/gui.py` — пользовательский интерфейс.
